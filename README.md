# Controle de Níveis de Água 🚰

Sistema simples de monitoramento de reservatório desenvolvido para a disciplina de Desenvolvimento de Sistemas.

## 🚀 Tecnologias Utilizadas
- **Python 3**
- ### 📦 Bibliotecas Padrão (Standard Library)
*Não requerem instalação externa:*
- **`random`**: Utilizada para simular a leitura do sensor de nível de água de forma aleatória.

### 🛠️ Bibliotecas de Terceiros (Via PIP)
*Necessário instalar antes de executar:*
- **`colorama`**: Responsável pela estilização e cores das mensagens de alerta no terminal.
- **Random**: Para simulação de dados do sensor.

## 📋 Requisitos da Atividade
O sistema deveria:
- Utilizar listas para mensagens e níveis.
- Implementar uma função para definir cores conforme o risco.
- Simular o monitoramento sem necessidade de input manual.

## 🔧 Como rodar o projeto
1. Clone o repositório.
2. Instale a biblioteca necessária: `pip install colorama`.
3. Execute o arquivo: `python nome_do_seu_arquivo.py`.
